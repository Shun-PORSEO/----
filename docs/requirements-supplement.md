# 要件定義の補完と未決事項への提案

元の要件定義（2026年9月24日版）で決まっていなかった点を、実装にあたって以下のように補いました。**太字**は確認をお願いしたい判断です。

## 1. 未決事項への提案

| 未決事項 | 提案（実装済みの内容） |
|---|---|
| 試行ユーザーの条件 | 要件の案（5〜10社・3ヶ月・月1万円・月1回のフィードバック面談・削減時間の記録）をそのまま紹介ページに掲載。削減時間はアプリ内で記録し、**中身を含まないCSV（件数と分数のみ）**で運営へ送ってもらう形にした |
| 最初に提案する商工会議所 | **旭川 → 札幌 → 函館の順を提案**。旭川は道北の中小企業が集積し、札幌より講師枠が取りやすく、事例を作ってから札幌に持ち込める。アプリ側の対応は不要 |
| ローカル保存とAI非保持の技術設計・説明文 | [privacy-explanation.md](privacy-explanation.md) に記載。**ZDR（ゼロデータ保持）契約をAnthropicと結ぶこと**を本番公開前の必須作業とした |
| PC故障時のバックアップ方針 | 合言葉で暗号化したバックアップファイル（`.kioku`）を外付けディスク／USBメモリに保存。ホーム画面で30日以上未実施なら警告。合言葉は運営者も知らない（＝運営者も復元できない）ことを明示 |
| サービス名とキャッチコピー | 仮称 **「会社の記憶帳」**、コピー **「社長の判断を、会社の資産に。」**、サブ「道内社長のAI活用パートナー」。環境変数 `SERVICE_NAME` で差し替え可能（紹介ページの本文は HTML を直接編集） |
| 相談を代行できる提携先 | アプリ外の課題。相談処理を `ops/consult-triage.js` のキュー（Markdown）に集約したので、提携先はキューを見て回答するだけで引き継げる |

## 2. 要検討事項への対応

| 要検討 | 対応 |
|---|---|
| PC故障時のデータ消失 | 上記の暗号化バックアップ＋復元。保存先フォルダにある `会社の記憶.md` は人が読める控え |
| 複数PC・Mac Safari | Mac の Chrome/Edge は対応。Safari・Firefox・スマホは「お試しモード（ブラウザ内保存）」で利用可。複数PCは「バックアップで移す」か「同期フォルダ（OneDrive等）を保存先にする」を案内（後勝ち上書きの注意つき） |
| 権限の再許可が頻発しないこと | フォルダのハンドルを IndexedDB に保存し、次回は「保存先フォルダを開く」ボタン1回で再開。Chrome 122 以降の「毎回許可する」を選べば確認自体が出ない |

## 3. 実装で補った仕様

### 会員・認証
- 試行版は **会員コード方式**（環境変数 `MEMBER_CODES`）。アカウント登録・パスワード管理をなくし、サーバーに個人情報を持たない。
- 1会員あたり1時間120回の上限（`RATE_LIMIT_PER_HOUR`）でAPI費用の暴走を防ぐ。
- 本格運用（数百社規模）では、決済サービス（Stripe 等）の顧客IDと会員コードを紐づける管理画面を追加する想定。

### 「残す」
- 記憶の種類：**理念／判断／業務手順／顧客／人・組織／事実**の6種類。
- 記憶の入口：AI聞き出し、ホームの「すぐ残す」（AIが種類とタイトルを付ける）、手入力、自社AIの回答、AIニュースの解説。
- 原本は `kioku.json`（JSON）。同じフォルダに `会社の記憶.md`（人が読む控え）、`対話ログ/`、`出力/`、`調査レポート.md` を書き出す。

### 聞き出し
- 1回10分のタイマー（超えても続行可、今日の分は常に保存済み）。
- 毎回「経営デザインシートで最も埋まっていない項目」を重点項目としてAIに渡す。
- AIは「次の質問」「シートの更新後全文」「記憶の候補」を構造化出力（JSONスキーマ）で返す。反映された項目は画面右で緑に光る。
- 音声入力はブラウザ標準の音声認識。**音声がブラウザ提供元（Google/Microsoft）で文字起こしされる場合がある**ことを画面に明記し、OS の音声入力も案内。

### 「答える」
- 質問に関係する記憶を最大8件・6,000字まで選ぶ（理念は判断の軸として1件添える）。
- 回答には根拠にした記憶を「（記憶：タイトル）」で示し、一般論と区別させる。
- 回答をワンクリックで「判断」の記憶として残せる。

### 「出す」
- 経営デザインシートは内閣府の枠組みに沿って11項目（自社の目的・特徴／A 外部環境／B これまで／C これから／D 移行戦略）。
- 充足率は「1項目60字で満点」の簡易指標。
- 出力：印刷・PDF（A4横1枚）、保存先フォルダへの HTML、Markdown。

### お悩み相談
- AIが範囲を事前判定（IT・AI活用のみ）。範囲外は商工会議所の経営相談窓口・北海道よろず支援拠点・士業を案内。
- 受付は Forms（`CONSULT_FORM_URL`）。アプリは「相談文をコピー → フォームを開く」の2手順。月1回の利用状況は社長のPCに記録（ソフト制限）。
- 運営側は `ops/consult-triage.js` で「範囲判定・分類・プールの類似事例を踏まえた回答案・自信度」を作り、**範囲内かつ（自信度0.7未満 または 前例なし）のものだけ**を要確認として上げる。回答確定分は会社名を除いて「悩みと解決策プール」（`ops/data/pool.jsonl`）へ。

### AIニュース
- 公開ページ（`/news.html`）は無料・集客用。配信データは `public/news/index.json`。
- `ops/news-draft.js` がWeb検索で今週の話題を調べ、配信データ・メルマガ本文・ポッドキャスト台本の下書きを作る。**公開前に人が出典を確認**してから `--publish`。
- 会員は各記事で「自社への影響を解説」を押すと、関係する記憶に照らした解説を読める。

### AIモデル
- 既定は `claude-opus-5`（環境変数 `CLAUDE_MODEL` で変更可）。拒否応答時はサーバー側フォールバック（`fallbacks: "default"`）で別モデルに自動再試行。
- 機能ごとに思考の深さ（effort）を調整：調査=high、聞き出し・回答=medium、整理・判定=low。
- 月額2万円の原価管理のため、試行中に1社あたりのAPI費用を計測し、必要なら聞き出し・整理を軽いモデルに切り替える。

## 4. MVPで後回しにしたもの（要件どおり）

道内同業ベンチマーク／会計ソフト連携／事業計画書など追加テンプレート／金融機関向け管理画面／お悩みプールの検索機能（プールは溜めるのみ）。

## 5. 残るリスクと対策

| リスク | 対策 |
|---|---|
| AIの誤回答 | 根拠の記憶を明示、一般論と区別、相談は人が最終確認。調査結果は社長がチェックしてから取り込む |
| PC故障 | 暗号化バックアップと毎月のリマインド |
| 大手の汎用AIとの機能差の消失 | 機能ではなく「道内特化・専門家の伴走・蓄積された相談事例」で差別化（要件どおり） |
| 運営者1名への依存 | 相談処理をキュー化・プール化し、提携先が引き継げる形に |
| 音声データの外部送信 | 画面で明示し、OS音声入力の代替を案内 |
