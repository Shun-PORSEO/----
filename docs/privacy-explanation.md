# 社長への説明文とデータ設計

## 1. 社長への説明文（そのまま使える平易版）

> **会社の記憶帳の3つのお約束**
>
> **1. 原本はあなたのPCだけ**
> 会社の記憶は、社長のパソコンの中の「会社の記憶」フォルダにだけ保存します。私たちのサーバーには保存しません。フォルダの中身はメモ帳でも開けます。
>
> **2. AIに送るのは、質問のときの必要な部分だけ**
> 質問や対話のときに、その質問に関係のある記憶だけを選んでAIに送ります。何を送ったかは、毎回画面で確認できます。
>
> **3. AIの学習には使いません**
> 送った内容をAIの学習に使わない、企業向けのAIサービスを使っています。回答が終われば、私たちの中継サーバーにも内容は残りません。
>
> **ご注意いただきたいこと**
> - パソコンが壊れると記憶も失われます。月に1回、「設定・バックアップ」から暗号化したバックアップを作り、USBメモリなどに保存してください。合言葉は私たちも知らないため、忘れると復元できません。
> - 音声入力を使うと、音声がブラウザ（Google / Microsoft）の仕組みで文字に変換される場合があります。気になる方はキーボードか、パソコンの音声入力（Windowsキー＋H）をお使いください。
> - お悩み相談のフォームに書いた内容は運営者に届きます。社員の個人情報やお客様の名前は書かないでください。

## 2. データの流れ（技術者向け）

| データ | 置き場所 | サーバーに届くか |
|---|---|---|
| 会社の記憶・経営デザインシート・対話ログ・削減時間 | 社長のPCのフォルダ（`kioku.json` ほか） | 届かない（質問時に必要部分のみ一時的に通過） |
| フォルダのアクセス権（ハンドル） | ブラウザの IndexedDB | 届かない |
| 会員コード | ブラウザの localStorage | 毎回ヘッダーで送信（照合のみ） |
| AIへの質問・対話 | — | 中継サーバーをメモリ上で通過し Anthropic API へ。保存・ログなし |
| 公開情報の調査 | — | 会社名・URL・所在地・業種のみ |
| お悩み相談 | Forms（運営者） | アプリ経由では送らない |
| 月次CSV | 社長が手動で運営へ | 件数と削減時間のみ（記憶の中身は含まない） |

### 中継サーバーの実装上の約束（`server/`）
- リクエスト本文をディスク・ログに書かない。エラー時は種類とHTTPステータスのみ `console.error`。
- すべての応答に `Cache-Control: no-store`。
- CSP で外部スクリプトを禁止（`script-src 'self'`）。AIの応答はエスケープしてから表示。
- 会員ごとの利用回数（件数のみ）をメモリに保持。再起動で消える。

### Anthropic 側の設定（本番公開前に必須）
1. Anthropic の商用API（Claude API）を使う。**商用利用規約により、APIへの入力・出力はモデルの学習に使われない。**
2. 要件の「データ保持をしない」を満たすため、**Anthropic と ZDR（Zero Data Retention）の取り決めを結ぶ**（営業窓口経由）。ZDR 未締結の場合、Anthropic 側で安全性確認のため一定期間保持されることがあるため、説明文の3番は「学習に使わない」までに留める。
3. ZDR の対象範囲は機能ごとに異なる場合があるため、**Web検索（登録時の調査で使用）が対象に含まれるかを契約時に確認**する。調査で送るのは公開情報の検索に必要な会社名等のみ。
4. モデルを変更する場合、ZDR の対象外のモデル（例：30日保持が必須のモデル）を選ばないこと。

## 3. PC故障・移行への備え

- **暗号化バックアップ**：PBKDF2-SHA256（31万回）で合言葉から鍵を作り、AES-GCM 256bit で暗号化（`public/js/backup.js`）。合言葉はどこにも保存しない。
- **復元**：新しいPCで保存先フォルダを選び、「設定・バックアップ」から復元。
- **人が読める控え**：保存のたびに `会社の記憶.md` を同じフォルダに書き出すので、アプリが使えなくなっても記憶は読める（解約後も同様）。
